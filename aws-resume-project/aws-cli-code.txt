------Overview of the Project----

The purpose of this file it to wlak through the steps/code I used to set up a static website using the AWS CLi. 
I orginally decided to use an s3 static website and unblock public access but...\
I decided to do this project using s3, cloudfront and cloudwatch. So I made the s3 private again after step 5. 


----Here are the steps I used to complete this project----

1. Create the s3 bucket 
aws s3api create-bucket --bucket aws-resume-bucket-ah --create-bucket-configuration LocationContraint=us-west-1

2. Sync Files to s3 bucket (my-resume-bucket-ah)
aws s3 sync aws-resume-project/ s3://aws-resume-bucket-ah

3. Checked to make sure files have uploaded sucessfully
aws s3 ls

4. How to actually begin to host a static website 
aws s3 website aws-resume-bucket-ah --index-document index.html

5. Need to make the unblock public access --> giving people the ability to reach the website. 

    5a. To check if the bucket has public access or not 
    aws s3api get-public-access-block --bucket aws-resume-bucket-ah

aws s3api put-public-access-block \
--bucket aws-resume-bucket-ah \
--public-access-block-configuration \
BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=false,RestrictPublicBuckets=false

BlockPublicAcls - Prevents new ACLs (an older, per-object permission method) from granting public access
IgnorePublicAcls - Ignores any existing public ACLs, even if some are already set
BlockPublicPolicy - Prevents a bucket policy from granting public access
RestrictPublicBuckets - Restricts access even if a bucket policy technically allows it, for buckets AWS considers "public"

This is when I decided to use s3, cloudfront, cloudwatch. SO I made the s3 bucket private again.

----CloudFront Steps----

1. Create an Origin Access Control --> OAC AWS Origin Access Control (OAC) is a security feature in Amazon CloudFront that protects private backend resources—like Amazon S3.
aws cloudfront create-origin-access-control \
--origin-access-control-config \
Name=aws-resume-oac,SigningProtocol=sigv4,SigningBehavior=always,OriginAccessControlOriginType=s3

    1a. How to view OAC
    aws cloudfront list-origin-access-controls
